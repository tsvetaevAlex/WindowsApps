# Visual.Logger
это клиент серверное приложение, вспомогательный инструмент для разработчиков
представляет из себя:

## Visual.Logger.GUI.Server
 * серверная часть это .NET WIndows Form GUI приложение внешне выглядит как консоль. современный плоский дизайн
   *   в работе слушает 127.0.0.1:4000 и показывает полуечнные сообзнения в своем окне.
  *   варианты применения.
    *     для меня это хороший инструмент при отладке GUI и больших консольных приложений,
      т.к. можно из любой точки кода одной строкой строкой лтправить любое сособзение,
      для ослеживания изменения состояний и содержимого во время работы приложения.<br>
  * так же ечрез эту консоль можно организовать интерактив с пользователем. информирование подсказки и прочее.
   ```
используетс самый простой и надежный метод коммуникации socket 
```


## Visual.Logger.Console.Client | MVP версия
*  Консольный клиент к logger серверу. так современный плоский дизайн сейчас это  просто отправляет сообщения
*  в данный момент эьто такая же консоль. куда можно написать сообщение и оно появится в серверной части.
*  мы с дочкой так дома перепиваемся в тайне от мамы (свой messenger 😉)
